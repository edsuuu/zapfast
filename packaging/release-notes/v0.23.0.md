ZapFast 0.23.0 separa o desfoque das prévias do desfoque das mensagens e instala o servidor MCP no Claude Code com um clique.

**Atualizar pelo apt:** `sudo apt update && sudo apt upgrade`. Para instalar pela primeira vez, veja [Instalar este fork](https://github.com/edsuuu/zapfast#instalar-este-fork-debian-ubuntu-e-derivados), ou baixe o `zapfast_0.23.0_amd64.deb` abaixo e rode `sudo apt install ./zapfast_0.23.0_amd64.deb`.

## Novidades

- **Instalar no Claude Code.** Com **Configurações > Sistema > Acesso de agentes (MCP)** ligado, a linha **Instalar no Claude Code** roda `claude mcp add --scope user zapfast -- /usr/bin/zapfast mcp`, valendo para todos os projetos (um `zapfast` anterior é trocado). **Copiar comando** copia o mesmo comando para rodar num terminal, o único caminho no Flatpak. O `claude` é procurado no PATH e onde os instaladores o põem, como `~/.local/bin`. Depois de instalar, abra uma nova sessão do Claude Code.
- **Desfoque das prévias e das mensagens em separado.** Em **Configurações > Privacidade**, "Desfocar mensagens" virou **Desfocar prévias na lista de conversas** (a última mensagem embaixo de cada conversa) e **Desfocar mensagens na conversa aberta** (texto e mídia; os balões continuam nítidos). Quem tinha "Desfocar mensagens" ligado na 0.22.0 fica com as duas ligadas.
