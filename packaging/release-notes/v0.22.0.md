ZapFast 0.22.0 é a primeira versão do fork [edsuuu/zapfast](https://github.com/edsuuu/zapfast): um servidor MCP para agentes lerem e enviarem mensagens, desfoque de privacidade, canais num lugar próprio, o som de notificação no estilo do WhatsApp, a fonte e o contraste do WhatsApp Web atual, e um repositório apt próprio. Tudo o que está no ZapFast 0.21.3 do upstream continua aqui.

**Instalar pelo apt** (instala por cima do `.deb` oficial, e daí em diante as atualizações vêm deste fork):

```bash
curl -fsSL https://edsuuu.github.io/zapfast/apt/zapfast.gpg | sudo tee /usr/share/keyrings/zapfast.gpg > /dev/null
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/zapfast.gpg] https://edsuuu.github.io/zapfast/apt ./" \
  | sudo tee /etc/apt/sources.list.d/zapfast.list
sudo apt update && sudo apt install zapfast
```

Ou baixe o `zapfast_0.22.0_amd64.deb` abaixo e rode `sudo apt install ./zapfast_0.22.0_amd64.deb`. Precisa de Debian 12+, Ubuntu 23.04+ ou derivados (amd64).

## Novidades

- **Acesso de agentes (MCP).** `zapfast mcp` deixa um agente como o Claude Code usar a conta ligada no ZapFast: listar conversas, ler mensagens, enviar texto para uma conversa ou um número (inclusive celular brasileiro registrado sem o nono dígito) e esperar a resposta, que volta inteira mesmo quando vem em vários balões. Serve para testar um chatbot sem tomar o WhatsApp Web de quem está usando. Ligue em **Configurações > Sistema > Acesso de agentes (MCP)** e rode `claude mcp add zapfast -- zapfast mcp`. Fica desligado por padrão, conversas bloqueadas nunca aparecem e nada do que o agente lê ou envia vai para o log. As mensagens enviadas são reais e saem em seu nome; o WhatsApp pode banir contas que automatizam mensagens.
- **Desfoque de privacidade,** como no WA Web Plus. Em **Configurações > Privacidade**, desfoque as fotos, os nomes e números e as mensagens, na lista de conversas, no cabeçalho da conversa aberta e nos balões. Cada parte aparece ao passar o mouse.
- **Canais têm um lugar próprio.** O megafone no trilho, abaixo de Chamadas, lista os canais que você segue; eles saem de Conversas e do contador de não lidas. O clique direito silencia ou reativa todos.
- **Som de notificação no estilo do WhatsApp,** agora o padrão: "Pop" para mensagens e "Pop para menções". Os sons anteriores continuam nas Configurações, e você pode escolher um arquivo seu.
- **Fonte e contraste como no WhatsApp Web atual.** Cores, tamanho do texto das mensagens (15 px) e da lista, e a renderização do texto no tema escuro seguem o WhatsApp Web de hoje.

## Corrigido

- **O balão de "digitando" tem o tamanho de uma mensagem de uma linha,** em vez de quase o dobro da altura.

## Para quem mantém

- O ZapFast deste fork procura atualizações nas releases de edsuuu/zapfast, e o link "Código-fonte" abre este repositório.
- `packaging/deb/release.sh` compila em Debian 12 no Docker, cria a release com o `.deb` e publica o repositório apt assinado no GitHub Pages ([packaging/deb/README.md](https://github.com/edsuuu/zapfast/blob/main/packaging/deb/README.md)).
